AI-DLC / Codex Harness

説明HTMLを
導入先へ配布します

explanatory-html Skillと explanatory_html_writer Agentを、AI-DLCを使うProjectへ届けます。

Coreの正式な確認HTMLはGoが生成します。Agentは、人から補足説明を頼まれた場合だけ使います。

役割は2つに分かれます

Coreの正式HTML

ST-04、ST-05、ST-07、ST-08、ST-09とHuman Decisionの確認ページです。

Goの共通レンダラーが、正本データから決定的に生成します。

Agentの補足HTML

会話を知らない人向けの説明を頼まれた場合に作ります。

Skillの共通テンプレートを再利用し、正本の意味は変えません。

配布される流れ

  1. 本体Repository Skill、Agent、テンプレートを管理
  2. Go Bundle 配布対象として収集
  3. dist Projectレイアウトへ生成
  4. 導入先Project 必要なHTML説明で利用

導入先へ届くもの

  • .agents/skills/explanatory-html/SKILL.md
  • .agents/skills/explanatory-html/assets/explanation-template.html
  • .agents/skills/explanatory-html/agents/openai.yaml
  • .codex/agents/explanatory-html-writer.toml

必要なときだけ使います

  • 人がHTMLでの説明を明示的に依頼したとき。
  • 担当作業が、初めて読む人向けの説明HTMLを明示的に必要とするとき。
  • 通常のStage作業や、Coreが正式HTMLを生成しただけの場合は使いません。

守る境界

  • 補足HTMLは、Coreの正式レビューを置き換えません。
  • 確認済みSHA-256、State、Plan、Audit、正本JSONを変更しません。
  • 補足HTMLをStage proposalや人の承認として扱いません。
  • 外部フォント、CDN、外部JavaScriptを必要としません。

配布時の確認

Bundleテスト

Skill、Agent、テンプレート、UI metadataが配布一覧に入ることを確認します。

画面確認

デスクトップと約390px幅で、横切れ、重なり、読み順を確認します。
