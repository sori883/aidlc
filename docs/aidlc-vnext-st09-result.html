1 / CORE約束を固定

→
2 / OBSERVE事実を集める

Project内のEvidenceを条件ごとに結び付けます。

→
3 / DECIDE必要なら人間判断

未達や不明を、継続するか終了するか決めます。

→
4 / TERMINAL結果を固定

Outcome Currentを残し、Intentをcompletedにします。

全項目がEvidence付きで達成なら自動完了できます。一部達成、未達成、判断不能は、人間が決めるまでST-09に留まります。
