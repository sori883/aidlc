Core decision rules

Stage通過の決定規則

情報が足りない場合は短縮せず、安全側のexecuteにします。

候補Coreが採用できる条件条件不足
execute安全側の初期値。新しい作業が必要、または判断材料が不足。そのままexecute。
reuse実在するArtifactのversionとSHA-256が一致し、Stage Contractが再利用を許可。拒否してexecute、または人間へ確認。
not_applicableStage固有の決定規則が非該当と判定、または人間が例外判断。AIの理由だけでは不可。拒否してexecute、または人間へ確認。

Safety boundaries

今回固定する4つの境界

M3以降のStage詳細がなくても、AIが穴を埋めて進まないようにします。

v2 Intentは移行しない進行中v2 Intentの互換読み込みや自動変換は作りません。M2後は新しいvNext Intentだけを扱います。
初期Planは安全側ST-00を含む全Stageを消さずに持ちます。Evidenceがない短縮は行いません。
Coreだけが記録するAI Proposalとpersist済みCore Decisionを別経路にし、State／Audit mutationをCore関数へ限定します。
M3までST-00で安全停止固定Routeは有効にしますが、詳細未設計のStage本文をAIに推測させません。nextはCore-ownedなparked結果を返します。
