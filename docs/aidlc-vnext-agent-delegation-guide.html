AI-DLC vNext / CODEX

Stageの仕事は、専門Agentへ渡します。

親Agentは進行役です。各Stageの調査、設計、実装、確認は、固定された役割別Agentが担当します。次のStageを決める権限は、今までどおりCoreにあります。

1回の作業の流れ

1. Core

現在のStageと、許可されたWork Requestを決めます。

→
2. Conductor

固定割当を読み、適切なAgentへ仕事を渡します。

→
3. Stage Agent

指定範囲だけを作業し、結果をConductorへ返します。

→
4. 人間

承認が必要なときだけ、固定された結果を判断します。

ConductorやStage Agentが、次のStageを選ぶことはありません。

役割は混ぜません

CORE

進行と検証

Stage、State、Audit、完了判定を管理します。

CONDUCTOR

委譲と提出

Agentを起動し、結果をCoreコマンドへ提出します。

STAGE AGENT

個別作業

成果物候補、実装、または独立レビューを担当します。

Agentが変更できる範囲

proposal-only

指定された提案ファイルだけを書きます。製品コードやStateは変更しません。

assigned-worktree

ST-06で渡されたworktreeとBolt targetだけを変更します。

read-only

ファイルを変更せず、根拠付きの確認結果だけを返します。

Skillの使い方

  • すべてのStage Agentは、共通の$aidlc-stage-workを使います。
  • 文書、ブラウザ、表計算など、作業に合うSkillがある場合だけ追加で使います。
  • Stage Agentは別のAgentを起動しません。追加の視点はConductorへ依頼します。
  • Agentや必須Skillが見つからない場合、親Agentは代行せず停止します。

割当の正本

.codex/aidlc-common/data/vnext-stage-delegation.jsonが、StageとAgentの固定対応です。

./.codex/tools/aidlc delegation validate
./.codex/tools/aidlc delegation show ST-06 work
./.codex/tools/aidlc delegation show ST-07 review

Agentの所見は、Coreの検証や人間の承認を置き換えません。
